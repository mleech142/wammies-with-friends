## Wammies With Friends 3.0.0: game data from Wahapedia

BSData's 11th edition catalogues have been taken down, so the app now gets **all** its game data from Wahapedia's data export: every faction's units, weapons, points, wargear options, detachments and enhancements, along with the stratagems and rules it already used.

### What you need to do

1. **Back up your data folder first.** On the first start with the new data, the app changes your saved armies, comparisons and games in place. Copy the folder before you start 3.0: `%APPDATA%\Wammies With Friends\` on Windows, `~/.local/share/Wammies With Friends/` on Linux, or your Docker volume.
2. Open **Setup** and press **Download latest**. That is now the only download: units, rules and stratagems together.

### Your saved data carries over

- **What updates itself:** saved armies, Analytics comparisons, games and the app's own data. They switch to Wahapedia's records on their own, and every database ID stays the same.
- **Units not on Wahapedia** (mostly Legends and some Crucible units) stay in your lists with a note, so you can see what to replace.
- **The Setup page** shows what was changed and anything worth checking.
- **Share codes made with earlier versions** still import.

### Wargear is simpler

- **The Wargear button** on the Armies page now lists the unit's weapons with how many models carry each, beside the datasheet's own wargear options. Set the counts to match your models, for example 1 heavy weapon and 4 rifles.
- **No checks or points for options:** the app doesn't enforce the options or add their points ("per Multi-melta"). Follow the datasheet.
- **Wargear chosen in earlier versions** is reset to each datasheet's default loadout; set it again if you had changed it.

### Also changed

- **Upgrades for several datasheets** count as enhancements. Wahapedia's data doesn't have Unique Tags or BSData's per-datasheet limits, so the core rules apply.
- **The Setup page** no longer has the BSData folder, Browse or Re-import options.
- **Alternative weapon profiles** in Wahapedia's naming ("Weapon – profile") start unticked in Analytics after the first, as they did before.

Units, rules and stratagems are powered by [Wahapedia](https://wahapedia.ru/). The app is not endorsed by Games Workshop.

Download the zip for your system below, unzip it and run `WammiesWithFriends` (`.exe` on Windows).

**If you self-host with Docker:** back up the data volume, then `docker compose pull && docker compose up -d`, then press **Download latest** on the Setup page.
