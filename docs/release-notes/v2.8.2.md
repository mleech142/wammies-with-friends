## 40K Combat Simulator 2.8.2

### Fixed

- **Self-hosted copies: one person's wrong passwords no longer lock everyone else out.** Behind Docker, the app saw every visitor as the same device, so a stranger who kept typing wrong passwords for your name could stop you logging in for a minute at a time. Each visitor is now counted separately, and the address the app counts can't be made up by the visitor.

**If you self-host with Docker:** add `COMBAT_SIM_BEHIND_PROXY: "1"` under `environment:` in your `compose.override.yaml` (or download the new `compose.yaml`), then run `docker compose pull && docker compose up -d`. See the self-hosting guide.

Desktop users: nothing changes for you. Download the zip for your system below, unzip it and run `40kCombatSimulator` (`.exe` on Windows). Your data carries over.
