## Wammies With Friends 2.9.1

### Under the hood

Nothing changes in how the app looks or plays. This release reorganises the code so it's easier to keep improving:

- The app's web routes, once one 1,700-line file, are now split by area: Simulator, Analytics, Armies, saved scenarios, the Data tab and Setup.
- Play mode's rules engine now has a clearly defined set of functions the rest of the app may use, checked by a test.

### Fixed

- **Self-hosted copies:** the backup script (`scripts/backup.sh`) no longer swallows the commands after it when it's run from another script. Running it from cron, as the guide shows, was never affected.

Download the zip for your system below, unzip it and run `WammiesWithFriends` (`.exe` on Windows). Your data carries over.

**If you self-host with Docker:** `docker compose pull && docker compose up -d`.
