## Wammies With Friends 2.9.0

### New name

**40K Combat Simulator is now Wammies With Friends.** Everything works as before; only the name has changed.

- The app's header, tab titles and guides use the new name.
- The download is now `WammiesWithFriends-…-windows.zip` (or `-linux.zip`), and the program is `WammiesWithFriends.exe`.
- The GitHub page is now [github.com/mleech142/wammies-with-friends](https://github.com/mleech142/wammies-with-friends). Old links still work.

**Your data comes with you.** On first start, the app renames its data folder from `40K Combat Simulator` to `Wammies With Friends` (in `%APPDATA%` on Windows, `~/.local/share` on Linux). Armies, saved games, scenarios and settings all carry over, and you won't need to download BSData again. Close any older copy of the app before starting this one, so the folder can be moved.

### Faster and safer, especially on a shared server

- **One big Monte Carlo run no longer holds everyone up.** A run that would roll a very large number of attacks now does fewer runs (never under 100), and the Simulator says so. Ordinary runs are unchanged. Model counts stop at 99, as the pages' boxes do.
- **Clearer errors.** A request the app can't read now says what was wrong instead of showing a server error.
- **Self-hosted copies:**
  - Oversized requests are refused before they're read.
  - Other websites can't show the app's pages in a frame.
  - The game list loads faster as games pile up.
  - The Docker log no longer grows forever.
  - A new backup script saves the database, app data and settings nightly. See Backups in the self-hosting guide.

**If you self-host with Docker:** the image is now `ghcr.io/mleech142/wammies-with-friends`. Download the new `compose.yaml` (or change its `image:` line and add the `logging:` lines), then run `docker compose pull && docker compose up -d`. Your data volume stays the same.

Download the zip for your system below, unzip it and run `WammiesWithFriends` (`.exe` on Windows). You can delete the old `40kCombatSimulator` folder afterwards.
