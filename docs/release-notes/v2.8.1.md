## 40K Combat Simulator 2.8.1

### Fixed

- **Invulnerable saves that only work against melee or ranged attacks.** Wyches and Howling Banshees have their 4+ invulnerable save only in melee, and Imperial Knights, Titans, Rangers and Shroud Runners have theirs only against shooting. Before, these saves applied to every attack. Pages show them as, for example, "4+ (melee)". This changes results for 26 units in the Simulator, Analytics and Play. (#22)
- **Weapon rules no longer appear as unit abilities.** For example, an Archon no longer lists Devastating Wounds as a core ability. This affected most units. (#21)
- **"Twin Linked" weapons get their wound re-roll.** Some Aeldari and Drukhari weapons (Splinter Pods, Twin Splinter Rifles, Twin Shuriken Catapults) spell it without the hyphen. Before, the app didn't recognise them, so they had no hover text and no re-roll in the maths. (#24)
- **Chaos Daemons units can take an Instrument of Chaos and a Daemonic Icon**, and other units whose only options give an ability now have them too. (#19)
- **Aeldari and Drukhari each list only their own detachments.** Each Space Marine chapter now lists the core detachments and its own, not every chapter's. (#20)
- **Choices a datasheet refers to are now shown.** For example, the Raider's Vanguard of the Dark City abilities, Orders and C'tan Powers. (#23)

New modifiers added to the keyword glossary in a release now reach installs that already have their own copy of the app data.

Download the zip for your system below, unzip it and run `40kCombatSimulator` (`.exe` on Windows). Your data carries over. The BSData import runs again on first start.
