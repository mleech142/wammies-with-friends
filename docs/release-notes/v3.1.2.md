## Wammies With Friends 3.1.2

### Fixed

- **Self-hosted copies on Docker could stop on start after 3.0.** The image didn't include the file that moves data saved before 3.0 over to Wahapedia's data. It does now, and the app starts even without it.
- The note about reset wargear on the Setup page now says to set it again in the Wargear popup.

Download the zip for your system below, unzip it and run `WammiesWithFriends` (`.exe` on Windows). Your data carries over.

**If you self-host with Docker:** `docker compose pull && docker compose up -d`.
